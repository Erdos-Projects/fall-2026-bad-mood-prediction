# readme
## Problem Definition 
Sleep and exercise improve mood, both in the immediate term and over time. Here we propose the use of a publicly available dataset, Lifesnaps, to predict negative moods in individuals — before they occur — based on sleep and exercise data. 
This dataset captures thrice-daily mood ratings, alongside hourly exercise information and daily sleep measurements which were collected from FitBits worn over 4 months by 70 people. Alongside these measurements, this dataset also includes demographic and psychological trait data, alongside other hourly physiological metrics like temperature and heart rate. 
The bad-mood-predicor, applied to individual FitBit data, could allow wearable technology companies (e.g. FitBit) to provide customers with a bad-mood prediction warning tool, warning consumers about an impending bad mood based on their longitudinal sleep and exercise data. 
This project will combine three negative mood report factors: sad, tense/anxious and tired, but will not make independent predictions about the three. This project also will not make causal claims that poor sleep or a lack of exercise, for example, *cause* a bad mood. Also, any recommendations on how to improve or avoid a bad mood are outside the scope of this project.

## Data Gathering
	Data for this project is already publicly available for a one-time download at the following link: ~[https://zenodo.org/records/7229547](https://zenodo.org/records/7229547)~ and is described in detail in a paper at the following link: ~[https://www.nature.com/articles/s41597-022-01764-x](https://www.nature.com/articles/s41597-022-01764-x)~. Because the data is publicly available and participants are anonymized, there is no concern with respect to licensing or privacy.
