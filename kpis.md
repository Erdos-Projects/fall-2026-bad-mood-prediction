# KPIs
	The primary KPI for this project is model accuracy: given sleep and exercise data, how frequently can an individuals’ bad mood be predicted? We will also measure model sensitivity, accounting false alarm rate alongside true hit rate. We will consider tradeoffs concerning false alarm/ missed detection rates in our model, e.g. whether it is better to err on the side of false negatives versus false positives. 
	As a secondary goal, we will evaluate whether participants’ responses on the psychological metrics enhance model performance.
